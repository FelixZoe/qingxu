# 清序产品范围

## 定位

清序是一款面向个人的简体中文任务管理器。它追求低干扰、本地优先和可自托管，不复制 Things 或其他产品的品牌、UI 与专有交互。

## 当前版本

- 收集箱、今天、番茄钟与设置四个核心视图；
- 任务标题、备注、开始时间、截止时间、完成、取消与软删除；
- 搜索、快速新增、桌面与紧凑布局；
- Windows、iOS 本地持久化与自托管双向同步；
- Web 本地任务管理；
- iOS 系统原生底部导航与 iOS 26 Liquid Glass；
- Windows Portable ZIP、现代简体中文 Setup EXE、unsigned IPA 与 Web ZIP；
- Docker、1Panel/OpenResty、自动 Release 和生产自动部署。

## 后续演进

以下能力只有完成模型、迁移、跨端同步和自动测试后才进入正式范围：

- 标签、领域、标题分组、重复任务与清单项；
- 本地提醒、日历整合；
- JSON 导入导出和可视化备份恢复；
- Web 安全凭据方案与 Web 多端同步；
- 更大数据量的增量同步和客户端端到端加密。

团队协作、权限矩阵、看板、甘特图、工时统计和 AI 自动拆解不属于当前个人任务核心。

## 质量门槛

- 无网络时核心任务操作仍可用；
- 同步失败不破坏本地数据，重试不产生重复任务；
- 密钥不进入普通配置、日志、Git 或 Release；
- 发布必须经过 Flutter/Go 测试、三端构建、容器构建与生产版本校验；
- 部署目录不可变，同一提交可安全重跑，失败可回滚；
- 文档只描述已经实现的行为，规划必须明确标为后续能力。
