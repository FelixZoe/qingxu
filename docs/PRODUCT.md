# 产品规格

## 定位

清序是一款面向个人的任务管理器。它借鉴 Things 的低干扰体验，但不复刻其品牌、视觉资产或专有交互。

## 第一版范围

- 收集箱、今天、计划、随时、日志
- 领域、项目、标题分组
- 任务备注、标签、开始日期、截止日期
- 重复任务、清单项、搜索
- 本地提醒
- 离线创建、编辑、完成与删除
- 多设备增量同步和冲突合并
- JSON 完整导出与导入

## 暂不进入第一版

- 团队协作、评论、权限矩阵
- 看板、甘特图、工时统计
- AI 自动拆解任务
- 第三方日历双向同步

这些功能会显著增加复杂度，不能影响个人任务核心体验。

## 交互基准

- 桌面端支持 `Ctrl/Cmd + N` 快速新增、`Ctrl/Cmd + K` 搜索。
- 完成任务有轻量动画，但列表重排延迟到动画结束后。
- 编辑器自动保存；关闭编辑器不弹确认框。
- 日期概念分开：`开始日期` 决定何时出现，`截止日期` 表示最后期限。
- 删除先进入软删除状态，跨端同步确认后保留墓碑记录。

## 质量门槛

- 本地操作 100ms 内反馈。
- 无网络时所有核心任务操作可用。
- 同步重试不产生重复任务。
- 数据库迁移、协议兼容和导入导出必须有自动化测试。
- Web 与 Windows 支持键盘完整操作；iOS 支持动态字体和 VoiceOver。
